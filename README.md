# OIBSIP_DataAnalytics_Task4

## 📌 Objective
Predict the quality of wine based on its chemical characteristics using three machine learning classifier models — Random Forest, SGD Classifier and Support Vector Classifier (SVC).

---

## 🔢 Steps Performed
1. **Data Loading & Exploration** — Loaded dataset, explored shape, nulls and duplicates
2. **Data Visualization** — Visualized quality distribution and feature correlations via heatmap
3. **Data Preprocessing** — Dropped irrelevant columns, split data into train/test sets, scaled features
4. **Model Training** — Trained Random Forest, SGD Classifier and SVC models
5. **Model Evaluation** — Compared accuracy scores across all three models
6. **Visualization** — Created model comparison bar chart and confusion matrix
7. **Conclusion** — Identified Random Forest as the best performing model

---

## 🏆 Model Results
| Model | Accuracy |
|-------|---------|
| Random Forest | 69.87% |
| SVC | 63.76% |
| SGD Classifier | 50.22% |
